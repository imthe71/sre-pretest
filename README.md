# 題目一：找出出現次數最多的單字

## 題目需求

讀取 `words.txt` 的內容，找出重複出現最多次的單字。比對時不分大小寫，例如 `The` 和 `the` 要算成同一個單字；逗號、句點、驚嘆號等標點不算單字的一部分。

輸出格式如下：

```text
<出現次數> <單字>
```

題目範例的結果為：

```text
4 twinkle
```

## 解題想法

我先把檔案整份讀進來，再用正規表示式把文字中的單字抓出來。這樣 `twinkle,`、`twinkle!` 都會被當成 `twinkle`，不會因為後面的標點不同而被分開計算。

接著把每個單字轉成小寫後統計出現次數。這一步使用 Python 內建的 `Counter`，可以直接得到每個單字出現幾次。

最後找出次數最高的單字並輸出。若有多個單字同樣高頻，程式會選擇最早出現在檔案中的那一個，讓每次執行結果都一致。

## 執行方式

```bash
python wordfreq.py words.txt
```

預期輸出：

```text
4 twinkle
```

## 測試

```bash
python -m unittest -v
```

測試內容包含：

- 題目提供的大小寫與標點情況。
- 兩個單字出現次數相同時的處理。
- 空白或只有標點的檔案。

## 複雜度

程式只會由頭到尾讀一次文字，因此時間複雜度是 `O(n)`；`n` 是檔案內的單字數量。
