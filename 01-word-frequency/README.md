# 題目一：找出出現最多次的單字

## 題目

讀取 `words.txt`，找出出現次數最多的單字。大小寫不分，例如 `the` 與 `The` 視為同一個單字。

## 執行方式

```bash
python word_frequency.py words.txt
```

使用題目範例檔案時，輸出為：

```text
4 twinkle
```

## 做法

1. 讀取檔案內容後，統一轉成小寫。
2. 排除逗號、句號、驚嘆號等標點符號，再拆成單字。
3. 用計數器統計每個單字出現次數。
4. 找出最高次數並輸出單字。

題目沒有規定最高次數同分時只能留一個，因此程式會把所有同分的單字都輸出，並依字母排序，讓結果固定。
